# SentimentScope

AI-powered Multi-Domain Sentiment Analysis Platform built using BERT, PyTorch, Flask, React, and Docker.

## Features

* Real-time sentiment prediction
* Batch CSV sentiment analysis
* Sentiment history tracking
* Confidence score visualization
* Interactive pie-chart analytics
* Dockerized deployment

## Tech Stack

* Python
* PyTorch
* Hugging Face Transformers
* Flask
* React.js
* Docker
* Pandas

## Project Architecture

User Input / CSV Upload
↓
React Frontend
↓
Flask REST API
↓
Fine-Tuned BERT Model
↓
Prediction Results & Analytics Dashboard

## Run Locally

Backend:

pip install -r requirements.txt

python api/app.py

Frontend:

npm install

npm start
